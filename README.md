# VibeMonitor

Минималистичный сервис мониторинга доступности сайтов с веб-интерфейсом.

## Возможности

- Проверка доступности сайтов по HTTP/HTTPS
- Индивидуальный интервал проверки для каждого сайта
- История проверок с детализацией (время, статус, HTTP-код, задержка)
- Логирование недоступных сайтов
- Защищённый паролем веб-интерфейс
- Адаптивный дизайн (тёмная тема)
- Настраиваемое название проекта
- Счётчик сайтов в мониторинге
- Индикация последнего инцидента с временем
- Настраиваемый порог скрытия инцидентов
- Сохранение сессий при перезапуске контейнера (срок жизни 7 дней)

## Требования

- Docker
- Docker Compose

## Быстрый старт

1. Клонируйте репозиторий:

```bash
git clone https://github.com/umaxk/vibesitemonitor
cd vibesitemonitor
```

2. Создайте файл `.env` с паролем:

```bash
echo "MONITOR_PASSWORD=your_secure_password" > .env
```

3. Запустите контейнер:

```bash
docker compose up -d --build
```

4. Откройте в браузере:

```
http://localhost:1485
```

5. Введите пароль и добавьте сайты для мониторинга.

## Конфигурация

### Переменные окружения

| Переменная | Описание | Обязательная |
|------------|----------|--------------|
| `MONITOR_PASSWORD` | Пароль для доступа к веб-интерфейсу | Да |
| `MONITOR_SESSION_TTL_SECONDS` | Срок жизни сессии в секундах (по умолчанию 7 дней) | Нет |
| `MONITOR_COOKIE_SECURE` | Передавать cookie только по HTTPS (`true`/`false`) | Нет |
| `MONITOR_CONFIG_PATH` | Путь к файлу конфигурации | Нет |
| `MONITOR_LOG_PATH` | Путь к файлу логов | Нет |

### Volumes

| Путь | Описание |
|------|----------|
| `./data` | Каталог с `config.json` и `monitor.log` (создаётся автоматически) |

При обновлении со старой версии перенесите `config.json` и `monitor.log` в `./data/`:

```bash
mkdir -p data
mv config.json monitor.log data/
```

Старые сессионные токены автоматически получат срок действия при первом запуске.

### Порты

| Порт | Описание |
|------|----------|
| `1485` | Веб-интерфейс |

### Настройки проекта

Настраиваются через веб-интерфейс (клик по бейджу в шапке):

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| Название проекта | Отображается в шапке и заголовке вкладки | VibeMonitor |
| Интервал проверки | Интервал по умолчанию для новых сайтов (сек) | 60 |
| Таймаут | Максимальное время ожидания ответа (сек) | 10 |
| Скрытие инцидентов | Сколько часов показывать информацию об инциденте | 12 |
